# 内容规划：5 职业 · 300 卡

> 配套文档：[技术方案](技术方案.md)
> 目标：5 个职业，每个 54 张专属卡 + 30 张中立卡 = **300 张基础卡**；
> 每张卡含 1 个升级版本（等效 600 条卡表数据）。

## 2. 五个职业

每个职业有一个**核心资源**、两个**关键词**，以及两条互相咬合的构筑路线。
关键词全部落在引擎的新增能力清单里（见第 4 节），不是纯文案。

| --- | --- |
| 核心资源 | 格挡 |

## 3. 数值基准

以「1 费 = 6 点伤害 = 5 点格挡 = 2 点力量 = 抽 1 张」为基准线：

| 模型 | 公式 | 示例 |
| --- | --- | --- |
| 单段伤害 | `6 × 费用` | 1 费 6，2 费 12 |
| 多段伤害 | `3 × 费用 × 段数` | 1 费 3×2 |
| 格挡 | `5 × 费用` | 2 费 10（给 12 属于超标，需负面） |
| 力量 | `2 × 费用 - 1` | 1 费 +2 力量 |
| 抽牌 | `1 张 / 0.5 费` | 0 费抽 2 属于超模，需消耗 |
| 状态 | 1 层易伤 ≈ 1 费，1 层中毒 = 0.5 费 | |

**升级规则**：数值 +30% 或费用 -1，二选一。传说卡升级改变机制而非数值。

## 4. 引擎需要新增的能力

当前引擎（v0.1）只有 damage / block / draw / energy / heal / status 六种效果。
支撑 300 张卡需要补以下关键词，工作量见第 6 节：

| 关键词 | 类型 | 实现要点 |
| --- | --- | --- |
| 反击 thorns | 状态 | 受击回调里反伤，注意与格挡结算顺序 |
| 壁垒 retain_block | 状态 | 回合开始清格挡时保留一半 |
| 灼烧 burn | 状态 | 回合末扣血并 -1，可叠加 |
| 炽热 hot_hand | 卡牌修正 | 计算伤害时读手牌数 |
| 背刺 backstab | 卡牌修正 | 读目标 block == 0 |
| 连环 combo | 状态 | 记录本回合攻击牌数 |
| 圣印 seal | 状态 | 回合末按层数触发效果队列 |
| 溢流 overflow | 规则 | 治疗封顶逻辑改造 |
| 召唤 summon | 实体 | 新增「友方单位」数组，需扩展战场与 AI |
| 标记 mark | 状态 | 伤害计算 +N 后移除 |
| 诅咒/状态牌 | 卡牌 | 进入抽牌堆的负面板 |

其中**召唤**是唯一需要改战斗场景结构的（敌人位变成「单位位」），建议单独排期。

## 5. 敌人与关卡

| 幕 | 普通敌人 | 精英 | Boss |
| --- | --- | --- | --- |
| 第一幕 枯林 | 10 | 2 | 1 |
| 第二幕 钟楼 | 10 | 2 | 1 |
| 第三幕 深渊 | 10 | 2 | 1 |
| **合计** | **30** | **6** | **3** |

- 每个敌人 3–5 个招式，`pattern` 循环；
- 精英带 1 个「机制」而非纯数值（如：反伤、召唤、封印手牌）；
- Boss 三阶段，血量过半换 pattern。

## 7. 生产管线（建议）

```
design/cards.xlsx  ──(tools/export_cards.py)──▶  data/cards.json
                                                        │
                                          tools/validate_cards.py
                                                        │
                                                     CI 校验
```

- 表格列：`id / 职业 / 名称 / 费用 / 类型 / 稀有度 / 目标 / 效果1 / 效果2 / 效果3 / 描述 / 升级效果 / 美术键`
- 校验规则：ID 唯一、职业合法、费用 0–3、效果键存在、状态名合法、描述中的数字与效果一致
- 描述自动生成：由效果数组拼装中文描述，避免「表里改了描述没改」

## 8. 下一步建议顺序

1. 先做**引擎关键词扩展 + 单测**（1 周），这是内容的地基；
2. 用**守誓者**一个职业打样 54 张，验证数值模型与手感；
3. 手感 OK 后再批量生产其余 4 个职业（可并行）；
4. 最后做召唤系统（它只影响驭兽人，可延后）。
